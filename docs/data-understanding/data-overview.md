# Data Overview

The project uses four operational datasets.

| Table | Purpose | Grain |
|--------|---------|-------|
| Users | User profile and behavioural attributes | One row per user |
| Transactions | Financial activity | One row per transaction |
| Notifications | User communications | One row per notification |
| Devices | Registered user devices | One row per user-device |

The Transactions table contains the primary behavioural data used to measure engagement, retention and churn.

The Users table provides demographic and product attributes used for segmentation.

Notifications provide communication history.

Devices provide platform information for exploratory analysis.
