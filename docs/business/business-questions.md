# Business Questions

## Design Principle

Each business question investigates the relationship between a customer behaviour (or attribute) and a business outcome.

Typical patterns include:

- Does X influence engagement?
- Does X influence retention?
- Does X influence churn?
- How does X affect Y?

---

## Approved Business Questions

### Engagement

1. Does transaction frequency influence user engagement?
2. Does Crypto adoption influence user engagement?
3. Does Premium plan adoption influence user engagement?
4. Does notification frequency influence user engagement?
5. Do merchant spending categories influence user engagement?
6. How does user engagement evolve over time across different countries?
7. Does device brand influence user engagement?

---

### Retention

8. Does transaction frequency influence user retention?
9. Does Crypto adoption influence user retention?
10. Does Premium plan adoption influence user retention?
11. Do referred users retain longer than non-referred users?
12. Does notification frequency influence user retention?

---

### Churn

13. Do failed or declined transactions influence churn?
14. Do specific transaction types influence churn?
15. Does country influence user churn?
